# ADR-002 · 角色权限模型与超级管理员可编辑的动态主页

日期：2026-09-16  
状态：已接受（用户要求：主页区分访客/管理员/超级管理员三种权限；超级管理员可修改主页头像、文字与背景，背景支持 GIF 等动态格式；降低模块耦合支持并行开发）  
关联需求：`../01-产品范围与功能规划.md` 第 7 节；`../02-总体架构与扩展规范.md`；`../03-内容模型与工具接入协议.md`；05 文档阶段 4  
替代记录：无

## 背景

账号系统上线后需要区分普通访客、内容审核者与站长。站点首页当前由构建期配置（`src/config/site.ts`）写死，更换头像/文案/背景都要改代码发版；用户要求头像、文字、背景可在线修改，且背景必须支持 GIF 等动态图片格式。同时多模块（博客/作品/工具箱/论坛/账号/站点配置）并行开发要求更严格的边界。

## 选择

| 方案 | 收益 | 成本与限制 |
| --- | --- | --- |
| A. 角色字段 + 站点配置 API（覆盖项存储，前端合并默认值） | 服务端强制鉴权；静态默认值兜底，后端离线时站点仍可用；只存覆盖项，语义清晰 | 前端需要一小段客户端增强脚本；首屏有一瞬默认值→覆盖值的切换 |
| B. 整站 SSR / CMS | 配置即所见 | 与「静态优先」架构冲突，引入常驻渲染依赖 |
| C. 背景图片上传到服务端 | 无外链依赖 | 需要文件存储、配额与安全治理；首版用 URL 引用（http/https 协议校验）即可满足 GIF 等动图需求 |

## 决定

1. **角色**（`backend/app/models/account.py`）：`member`（注册默认）/ `admin`（内容审核）/ `superadmin`（站点配置 + 角色管理）；访客 = 未登录。引导规则：数据库为空时第一个注册账号自动成为 superadmin；另支持 `NAYTIA_SUPERADMIN_CODE` 邀请码。superadmin 可改他人角色（不能改自己）。
2. **站点配置**（`site_config` 表，单行 JSON 覆盖项）：`GET /api/site-config` 公开；`PUT /api/site-config` 仅 superadmin。字段：`display_name / intro / avatar_url / background{mode,url,overlay}`。URL 仅接受 http(s)（拒绝 `javascript:`、`data:`）；背景 `mode=image` 时直接以 `background-image` 引用，GIF / WebP / APNG 等动图原生支持，`overlay`（0–0.9 暗色遮罩）保证文字可读。
3. **前端模块化**（`src/modules/`，见该目录 README）：每个模块只有 `index.ts` 一个公开入口；依赖方向固定 `site-admin → account + site-config`，互相无环；会话变化以 `naytia:session` 事件广播；共享基础能力放 `src/shared/`。页面渲染挂钩点为 `data-site-field` 属性与 `#site-background` 层。
4. **静态优先不变**：页面 HTML 内置默认值，后端可达时客户端覆盖渲染；失败静默回退。

权限矩阵：访客只读；member 论坛读写自己的内容；admin 可审核删除任何帖子/回复；superadmin 拥有 admin 全部能力 + 站点配置 + 角色管理。所有判定在服务端执行。

## 扩展影响

- 前端 `BaseLayout` 依赖 `modules/account` 与 `modules/site-config` 公开接口；`index.astro` 引入 `modules/site-admin`。后续论坛/工具箱前端按同一模式接入，不改既有模块内部。
- 后端 `models.py` 拆分为 `models/` 包（account/forum/favorites/site），路由按模块隔离，可并行开发。
- 头像/背景以 URL 引用，外链失效风险由站长管理；上传存储作为后续独立任务。

## 数据与回退

- 旧 `data/app.db` 无 role 字段，属开发期数据，直接删除重建；正式上线前完成迁移脚本（阶段 5 发布任务覆盖）。
- 站点配置 PUT 为浅合并：只更新本次提交的字段，未提交字段保留；`mode=none` 即回退无背景。
- 回退：停用 site-config 路由后前端自动回退内置默认值，静态站不受影响。

## 验证

- pytest 28 项通过：新增首个账号 bootstrap、member 403、角色管理与自我变更禁止、admin 审核删帖、站点配置公开读/超管写/浅合并/协议校验（拒绝 `javascript:` 与 `data:`）。
- 浏览器实测（2026-09-16）：注册首账号 → 角标「超管」→ 编辑面板修改昵称与 GIF 背景 → 实时预览 → 保存发布 → 刷新后配置持久恢复；`astro check` 0 错误，`npm run build` 通过。

## 重新评估条件

出现多管理员协作审核、站点配置多语言/分版本、或背景素材需要托管与防盗链时，重新评估为上传存储 + 配置历史版本。
