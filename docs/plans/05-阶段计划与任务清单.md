## 阶段 6：按需求持续扩展

| 候选功能 | 启动条件 | 独立交付边界 |
| --- | --- | --- |
| 时序计算工具 | 规则和使用场景明确 | 新工具模块 |
| 跨站内内容搜索 | 标签与列表不足以快速查找 | 索引生成器与搜索适配器 |
| 在线内容后台 | 文件编辑频率/成本明显增加 | CMS 适配器、身份与发布流程 |
| 复杂 MC 分析 | 有可验证算法、样例与性能需求 | 专项引擎、Worker/WASM、测试数据 |
| 文件导入导出 | 工具确实需要交换结果 | 格式协议、迁移与限制 |
| 评论/反馈 | 有维护与审核能力 | 论坛已承担主互动；站内评论或第三方组件另行评估 |
| 多语言/新主题 | 出现明确受众需求 | 文案资源与设计 tokens |
| 云端收藏/计算同步 | 本地收藏不够用、需要多设备 | 账号云存储、配额与迁移（依赖阶段 4 服务端） |
| 论坛进阶能力（私信、积分、附件） | 社区规模与审核能力支持 | 独立模块，逐项评估 |

每项按「需求 → 契约 → 实现 → 验证 → 发布」单独交付，不因列入候选就提前安装依赖或创建空模块。

## 首版完成定义

必须同时满足：四个导航入口（首页 / 作品 / 工具箱 / 论坛）、完整内容发布路径、真实博客/作品、两项工具、论坛与账号（至少本地演示版，满足阶段 4 验收）、可扩展接口、移动端/键盘可用、无草稿泄露、构建与核心检查通过、可发布可回退。

只做出漂亮首页、工具只显示卡片、论坛与账号停留在演示版而未记录正式化路径、依赖尚未锁定或没有发布回退记录，都不算正式项目完成。
