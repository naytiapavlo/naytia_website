# 01 · 产品范围与功能规划

更新日期：2026-09-16  
状态：规划。导航与视觉、论坛模块与账号系统为用户已确认要求（论坛与账号为 2026-09-16 新增）；具体工具优先级、发布流程和后台方案为建议。

## 1. 用户与核心路径

| 访客 | 主要需求 | 典型路径 |
| --- | --- | --- |
| 初次认识 UP 主的人 | 了解个人方向与代表作 | 首页 → 作品 → 视频或作品详情 |
| B 站观众 | 找教程补充、资源、适用版本 | 视频链接 → 作品详情 → 资源 |
| MC 技术玩家 | 查机制、运行计算、复现结果 | 工具详情 → 选择规则 → 输入 → 结果 |
| 玩家社区访客 | 聊机制、晒作品、提问互助 | 论坛 → 帖子 → 登录后回复 / 发帖 |
| 网站作者 | 低成本更新与维护 | 编辑内容 → 预览 → 校验 → 发布 |

## 2. 页面与路由

正式站采用可直接访问的路径。现有 Demo 的 hash 切换只作为视觉原型，不作为正式内容路由方案。

| 路径 | 功能 | 首版 |
| --- | --- | --- |
| `/` | 头像、简介、最近博客、精选内容入口 | 必做 |
| `/blog/` | 博客列表、分类/标签入口、分页 | 必做；不占顶级导航 |
| `/blog/[slug]/` | 正文、目录、更新时间、引用与关联内容 | 必做 |
| `/works/` | 作品列表，按类型或标签浏览 | 必做 |
| `/works/[slug]/` | 作品介绍、适用条件、视频与资源、作者署名 | 必做 |
| `/tools/` | 工具目录、分类、可用状态 | 必做 |
| `/tools/[slug]/` | 独立工具工作区、说明、输入与结果 | 必做 |
| `/forum/` | 论坛版块与帖子列表、发帖入口 | 必做 |
| `/forum/[threadId]/` | 帖子正文、回复与互动 | 必做 |
| `/login/`、`/register/` | 注册与登录（可由弹层承载，但需可直达、可返回） | 必做 |
| `/404.html` | 不存在的页面与返回入口 | 必做 |
| `/account/` | 个人中心：资料、我的帖子、收藏 | 后续 |
| `/tags/[tag]/` | 跨文章与作品的标签聚合 | 内容增加后启用 |
| `/search/` | 博客、作品、工具统一搜索 | 后续 |
| `/admin/` | 管理后台 | 确有在线编辑需求后评估 |

所有详情页拥有稳定 URL。改标题不自动改 slug；改 slug 必须维护跳转映射。历史 Demo 的 `#home/#works/#tools` 在迁移阶段按需映射到新路径。

## 3. 首页与视觉系统

- 白色为主，少量粉色与柔和辅助色；像素边框、图标和轻微硬阴影承担风格表达。
- 正文字体优先可读性，像素字体仅用于短标题或装饰；无需强迫全部中文使用像素字体。
- 头像、昵称、简介、标签、公开外链、推荐内容 ID 均从配置读取。
- 博客保留在首页，不因为顶级导航（现为四项）而丢失个人博客功能。
- 页面公共外壳统一管理导航、页脚、最大宽度、间距与移动端断点。
- 展示真实状态；不虚构阅读量、更新日期、在线状态或作品性能。
- 动效只作辅助，尊重减少动态效果的系统偏好。

## 4. 博客模块

### 首版

- Markdown 正文、代码块、图片与说明、标题锚点；有实际文章需要时加入公式渲染。
- 标题、摘要、分类、标签、草稿状态、创建/更新日期、封面与作者信息。
- 目录、关联作品与工具、引用来源、文章列表分页。
- 草稿只出现在受控本地或内部预览，不进入正式页面、RSS、搜索索引或 sitemap。
- 支持 RSS 与站点地图；内容链接可直接分享。

### 后续扩展

全文搜索、系列文章、修订历史、多语言、评论与订阅。评论和订阅分别作为独立集成模块，不进入文章正文模型的核心字段。

## 5. 作品模块

### 首版

- 标题、简介、作品类型、标签、图片/示意图、原理与使用说明。
- 游戏版本、平台、维度或环境限制、验证日期；未知信息明确显示未验证。
- 设计者、合作作者、技术来源与引用链接。
- 视频优先外链，播放器嵌入在性能与访问体验确认后加入。
- 下载资源采用版本化资源清单：名称、格式、适用范围、来源、大小、校验值等按可获得信息填写。
- 使用说明与更新日志；旧方案保留历史，并关联替代方案。

### 后续扩展

作品系列、参数比较、三维/结构预览、资源镜像、关联工具自动带入参数。后三项分别需要独立交互或文件协议，不放进通用作品卡片。

## 6. 工具箱模块

### 统一体验

每个工具包含用途、规则版本、适用范围、输入、示例、输出、错误说明、来源与更新记录。复杂工具支持进度、取消、重置和导出；简单计算无需模拟耗时进度。

状态至少区分：规划中、实验性、可用、已弃用。未实现工具不能显示可运行按钮。

### 与账号的联动

- 未登录可浏览工具目录与工具说明；登录后解锁收藏与个人使用记录。
- 收藏与「最近使用」按账号保存；工具计算本身仍在浏览器本地完成，登录不引入强制联网，账号仅承担身份与个人数据。
- 云端同步收藏与历史属于后续独立任务，启用前说明持久化与删除策略。

### 建议的首批工具

| 工具 | MVP 输入/输出 | 必须先明确的规则 |
| --- | --- | --- |
| 区块坐标助手 | 方块 X/Z → 区块坐标与区块内坐标 | 负坐标按向下取整；坐标范围与版本适用性 |
| 材料清单助手 | 数量与堆叠上限 → 组数、余量、容器需求 | 不默认所有物品为 64 堆叠；容器容量可配置 |
| 时序换算工具 | 游戏刻与秒的换算、周期频率 | 区分名义速率与实际运行速率；红石刻单独说明 |

优先完成前两项以验证接入协议；实际首发顺序可根据你的研究需求调整。种子、地形、结构或存档分析作为后续独立专项，不因工作区存在研究材料就认定已验证可用。

## 7. 论坛与账号模块（2026-09-16 纳入范围）

### 论坛

- 首版版块固定为：机制研究 / 作品展示 / 问答互助 / 站务公告；新版块通过配置增加，不改页面模板。
- 帖子包含标题、版块、作者、正文、创建时间与回复列表；回复包含作者、正文与时间。列表按最近活动排序，可按版块筛选。
- 浏览帖子无需账号；发帖与回复必须登录。作者可删除自己的帖子与回复。
- 正文为纯文本（保留换行），渲染前转义；用户内容不进入可信作者 MDX 流程。
- 不虚构帖子数据：演示示例帖明确标识「示例」；正式开放注册前需要审核、举报与删除流程。
- 首版不做：私信、积分等级、附件上传、板块管理员体系、第三方登录。

### 账号

- 轻量账号系统：用户名 + 密码注册登录；正式实现为服务端加盐哈希存储与会话管理，配基础限流。
- 账号作用于论坛（发帖、回复、删除自有内容）与工具箱（收藏、最近使用、后续云端同步）；博客与作品阅读、论坛与工具目录浏览不需要账号。
- 演示阶段：注册登录与论坛数据存于浏览器 localStorage，界面明示「演示版」边界；正式实现必须替换为服务端，接口契约保持不变。
- 权限一律在正式服务端校验；前端只负责引导登录与隐藏入口，不承担安全职责。

## 8. 内容管理与权限

- 首版由作者维护本地内容文件，提交后构建发布；访客阅读博客/作品、浏览论坛与工具目录无需账号，论坛发帖回复与工具箱个人功能需登录（见第 7 节）。
- 当文件编辑成为维护负担时再选择 Git 型 CMS 或数据库 CMS，沿用同一套内容契约。
- 后续若加入后台，作者、编辑、管理员权限必须服务端校验，隐藏按钮不等于权限控制。
- 云端收藏同步、用户上传等仍未纳入范围；纳入前需分别说明持久化、身份、删除与运营成本。

## 9. 首版不包含

插件商城、任意用户脚本执行、支付、在线多人协作、所有 MC 格式解析、自动抓取全量 B 站内容。论坛与轻量账号系统已于 2026-09-16 按用户要求纳入范围（见第 7 节）；复杂账号能力（第三方登录、多级权限、积分体系、私信）仍不在首版，允许未来接入。

## 10. 用户体验验收

- 手机、平板、桌面都能完成阅读、找作品、运行首批工具与浏览论坛。
- 未登录可以浏览论坛与工具箱；登录引导清晰，不打断浏览。
- 注册登录表单有校验与可读错误；登录状态刷新后保持，退出即时生效。
- 键盘可以访问全部交互；输入有标签，错误可读，焦点可见，200% 缩放不遮挡关键内容。
- 工具报错不使导航或其他页面崩溃。
- 文章、作品和工具相互关联，断链在发布前发现。
- 首发不保留示例文章或未标识的占位头像；不会把演示状态误认为正式功能。
