### 3.1 封面滚动：纯 CSS 无缝循环，不依赖 JS

- 一行 = **视口**（`.wk-row`：`overflow: hidden` + 两侧 `mask-image` 淡出）+ **轨道**（`.wk-track`）。
- 轨道里放**两份完全相同的分组**（`.wk-group`，每组的末尾间距用 `padding-right` 而不是 `gap`），
  关键帧只做 `translate3d(-50%)`——正好一份分组的宽度，因此循环点没有跳变。
  实测：分组各 1410px、轨道 2820px、可视区 980px。
- 第二份分组是**视觉克隆**（不是按钮、`aria-hidden="true"`），不重复进入键盘顺序与读屏。
- 悬停或聚焦时暂停（`:hover` / `:focus-within` → `animation-play-state: paused`），方便看清与点击。
- 滚动本身完全由 CSS 关键帧驱动：**没有 JS 也在滚**。
- 初版是两行反向（第二行 `animation-direction: reverse`）；按站长要求改成一行后，
  反向相关的样式与组件参数一并删除，没有留下只被注释掉的死代码。

### 3.2 时间轴：滚动进度线 + 节点逐个浮现

- 「阅读线」取视口 55% 处；进度线按阅读线相对时间轴顶部的位置绘制，
  **终点是最后一个节点的圆点中心**（按圆点实测位置换算，不写死百分比，行高变化也不会让线停在半空）。
- 节点用 `IntersectionObserver` 浮现，并高亮阅读线已越过的最后一个节点。
- 直接用 End 键或锚点跳到页尾时不会经过观察器，滚动回调里补一次显示——
  **这条是浏览器实测发现的**：跳转到底部时三个节点曾全部保持透明（见 4.2）。
- `html.wk-js` 由页面顶部一行内联脚本添加，浮现动效只在 JS 可用时生效：
  脚本没跑或抛错时时间轴内容照样完整可读（模块约定第 4 条「静态优先」）。

### 3.3 封面灯箱

- 原生 `<dialog>` + `showModal()`：模态语义、Esc 关闭、背景 inert 都交给浏览器。
- 灯箱宽度上限 700px：封面原图只有 672px 宽，不再往上放大，避免糊掉。
- 滚动轨道用的是同一批封面，**按图去重**后灯箱里每张只出现一次（`01 / 05`）。
- `←` `→` 切换、点击遮罩关闭、关闭后焦点回到来源封面按钮、打开时锁背景滚动（`html.wk-lightbox-open`）。
- 只有带 `videoUrl` 的条目显示「B 站视频 ↗」。

### 3.4 无障碍与降低动效

- 封面是 `<button>`（原生键盘可达、Enter/Space 可开），并带 `aria-label="放大查看封面：…"`；克隆份不参与。
- `prefers-reduced-motion: reduce` 下：关键帧动画关闭，滚动区变成**可手动横向滚动**的静态列表
  （内容一张不少）；浮现动效与过渡关闭，节点直接可读。

### 4.2 真实浏览器端到端

脚本：`tests/manual/e2e-works-showcase.mjs`（真实无头 Edge + CDP，非模拟环境）。

| 场景 | 结果 |
| --- | --- |
| 结构 | 1 行 × 5 封面 = 5 个可点击封面 + 5 个克隆；时间轴 3 节点；成果 7 条纯文本；**作品档案区块已不在 DOM** |
| 无缝循环 | 两份分组等宽（1410px）、轨道 = 2 × 分组宽（2820px） |
| 滚动方向 | 单行向左（-20.0 → -52.3） |
| 悬停暂停 | 悬停 `paused`、移开后恢复 `running`；封面 hover 位移 `-3px`、标题转主色 |
| 时间轴（滚动进入） | 3/3 节点浮现、进度线 72%、当前节点 = 2026.2、透明度 1 |
| 时间轴（回到顶部） | 进度线回退到 0%（不是只增不减） |
| 时间轴（直接跳页尾） | 进度线画到**最后一个圆点中心**、3/3 节点显示、当前节点 = 2026.2 |
| 灯箱 | `open` + `:modal`、图片加载成功（`dupe-infinite-block.jpg`）、计数 `01 / 05`、背景滚动锁定 |
| 灯箱导航 | `→` 到 `02 / 05`（`end-mechanism.jpg`）；`←` 回到 `05 / 05` 时出现 B 站链接 `BV1HaaxzuExT` |
| 灯箱关闭 | Esc 关闭、解锁滚动、**焦点回到来源封面**；点击遮罩同样关闭 |
| 键盘 | 封面按钮可获得焦点，`aria-label` 正确 |
| 降低动效 | `animation-name: none`、滚动区 `overflow-x: auto`、节点透明度 1、过渡 0s |
| 移动端（390 逻辑宽） | 文档无横向溢出（`scrollWidth == innerWidth`）、封面 212px、页头与 `/tools/` 完全一致 |
| 移动端灯箱 | 宽 367px、完全落在视口内 |
| 控制台 | **无未捕获异常** |

两条真实 bug 是这一步逼出来的（已修）：

1. **灯箱图片 src 为空**：卡片上的属性是 `data-lightbox-open`，脚本却读 `dataset.image`，
   两者对不上；端到端断言 `imageLoaded` 时才暴露。
2. **直接跳页尾时时间轴全透明**：只靠 `IntersectionObserver` 时，一跳到底不会触发任何交叉回调。

> 抓这些场景时脚本自己开空白标签页（`/json/new`）来连 CDP：无头 Edge 的默认 page target
> 会被别的验证脚本共用，对方一次跳转就会让断言读错页面（实测曾把 `/works/` 读成 `/docs/`）。

## 5. 已知限制

- **成果清单是纯文本，不带链接**（站长指定）：B 站视频的入口只在封面灯箱里，
  且只有「箱子纠缠 · 超距信号传输」有确切 BV 号；补链接只需在 `src/modules/works/data.ts`
  的对应条目填 `videoUrl`（灯箱会自动显示入口）。
- **「作品档案」区块已按站长要求删除**，因此 `content/works/*.md` 这三个作品文件
  当前不再由任何页面渲染（内容集合与 schema 保留，等阶段 2 的「作品详情页」再做）；
  成果清单里的高频闪门 · 猪人塔、无基岩 · 凋零笼改用 `data.ts` 手写条目。
- **封面文案由封面文字与站长口述整理**：第 2 张图本身没有文字，标题是站长指定的
  （「末地 / 地狱异步地物回溯」）。
- **灯箱不支持手势滑动**：移动端用左右按钮或键盘；未做触摸滑动，也未做缩放。
- **进度线依赖滚动事件**（rAF 节流）：无 JS 时只有静态轨道（纯装饰，不影响阅读）。
- **成果清单是手写数据**，不是从 B 站抓取：不引入外部接口，避免站点依赖第三方可用性。
- 与本站既有情况一致：**390px 宽度下页头导航（5 项）会把文档宽度撑到 438px**，
  `/tools/`、`/docs/` 同样如此，属公共外壳的既有行为，本次未改动。
